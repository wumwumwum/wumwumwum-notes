I created a python script that allows me to do a couple of things:

1.) running the script provides a menu for different OSINT searches

2.) each search category then provides a menu for the programs that perform the search

3.) selecting the program provides a menu for the search parameter selection

4.) you are then able to enter just your target info (ie. username, phone, email)

5.) once the query has completed, the script gives you the option to return to the main menu to run another search

The tools.json file can be modified to add new tools to the script. It also acts as a sort of register of the tools I commonly use.
